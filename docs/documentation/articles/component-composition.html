HTMLComponentElement Composition

HTMLComponentElement composition is the art of combining components or component parts to create views or new components.

With Cube components this process is very simple as composing any native html elements/components.

Slot

Slots are placeholders in the template that you can use to specify any place more components will take place. Slots can be named and a template may only have a maximum one unnamed slot.

const MyButton = () => { // set an un-named slot as a placeholder where content can be placed template`` }

This means that when you use a component, anything placed between the tags will replace the slot tag.

If a component does not have a slot tag in the template, anything placed inside the component tag will be ignored when rendered.

Headless Components

Headless component is a technique to split the visual parts of the component from the logic allow you to then define any interface to it. With Cube, you can split your component into the template, style and the logic then compose it into any type you wish.

Below is an example of how to split a component into different parts. This one is missing one for the logic, but you can just have a function you call with props to give you all the functionality you can attach to your template.

const defaultProps = { type: "button", disabled: false }; const buttonTemplate = ({type, disabled}) => html` `; const buttonStyle = ({type, disabled}) => { return { ":host": { ".btn": { all: "unset", padding: "8px 20px", borderRadius: 3, textTransform: "capitalize", background: "#222", color: "#fff", letterSpacing: "0.05rem", fontFamily: "sans-serif", cursor: "pointer" } } } }

With all the parts separate, you can then assemble the parts into a base component without modifications:

const BaseButton = (props) => { template`${buttonTemplate(props)}` } register(BaseButton, defaultProps, buttonStyle)

Or create variations by changing the style.

const CtaButtonStyle = (props) => { const btnStyle = buttonStyle(props); btnStyle[":host"][".btn"].background = "#900"; btnStyle[":host"][".btn"].border = "2px solid #222"; return btnStyle; } // the name of function is its tag name so cannot // have one point to the other otherwise they will have the same tag name const CtaButton = props => BaseButton(props) register(CtaButton, defaultProps, CtaButtonStyle)

Or compose the base component targeting the parts

const DiffButtonStyle = () => { return { ":host": { "base-button::part(btn)": { background: "purple", padding: "6px 20px" } } }; } const DiffButton = () => { template` `; } register(DiffButton, defaultProps, DiffButtonStyle)
