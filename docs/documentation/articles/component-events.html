HTMLComponentElement Events

Cube events is nothing new. It is based on the same native event listeners and custom events.

To set an event listener you simply use inline event listeners attributes which starts with on followed by the name of the event.

const handleClick = (event) => { // handle event } template``

This works with any native HTML DOM events as well as any custom events you dispatch inside a component.

const handleEvent = (event) => { // handle event } template`click me`

Event Dispatch

To be able to dispatch custom events Cube exposes the event dispatch helper which returns a simple function that you can call with the name of an event you want, can be anything, followed by an optional data to pass with this event.

const MyButton = () => { const dispatch = eventDispatch(); dispatch("somecustomevent", {data: "sample"}) }

You can use this to dispatch events of any type with any data which you can then listen to on the component tag just like listening to any other native event.
