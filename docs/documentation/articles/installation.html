Installation

You can use Cube directly in the browser using the CDN link.

This will add everything you need in the BFS object in window object you can read from Cube.

const {template, register} = window.BFS.Cube;

You may also install in a Node environment using npm.

npm install @beforesemicolon/cube

Then you can import and use it in your project like any other package

import {template, register} from "@beforesemicolon/cube"
