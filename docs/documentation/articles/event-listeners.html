Event Listeners

Cube template event listeners are just normal HTML inline event attributes that must start with on, e.g: onclick, onloading, onchange, etc.

const handleClick = (event) => { alert("clicked") } html``

You can simply pass it already defined function or create one inline.

This works for any event dispatched by the element. It can be native HTML elements or custom elements from web components or manually dispatched.

Event Listener Options

One thing that is specific to Cube is the ability to specify any valid addEventListener option as a comma separated event attribute value

This ability solves the need for specifying event listener options that most UI frameworks do not account for. This will save you from getting element reference just so you can set event listener options.

const singleClick = () => { console.log("clicked once") } html``;
