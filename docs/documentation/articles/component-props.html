Component Props

Props is a now famous term for attributes that the components react to in order to update the DOM. Natively they are known as observed attributes. Cube adopted the term props because it maps to the component host properties and props is short for properties

By default, Cube will trigger updates on the DOM when props change. If you want to do perform any logic when that happens, there is the onUpdate lifecycle that is called with the information of the prop that changed.

To define your "props", you simply need to provide a default data for them as the second argument when you register your component.

register(MyComponent, { label: "Hello World", additionalValue: true })

Cube will set these props with the provided value on the component host as properties and your component function will be called with a readonly version of this object once. Each of these properties will become a function, a getter, which returns the value of the prop.

The property names are camelcase and will map to a kebab-case version of it as element attribute.

const comp = document.createElement("my-component"); // access and update the property comp.additionalValue = false;
