Component State

Cube does not have the concept of state. Any piece of data inside a component can be considered state in this case.

const MyComponent = () => { const greeting = "Hello World"; template`

${greeting}

`; } register(MyComponent)

However, there are cases when you want a particular internal data change to trigger the DOM to update. For that Cube has dynamic expression which you can use to mark places in the DOM that will react to internal changes.

state helper

The state helper is the closest thing that comes to local state management because it triggers DOM update on every change.

const MyComponent = () => { const [greeting, setGreeting] = state("Hello World"); template`

${greeting}

`; } register(MyComponent)

The state helper takes an initial value and returns an array with a getter and a setter functions.

In most cases you can do fine with derived states therefore you should only need to use state when you need to manually trigger the DOM to change with a value.

Derived state

You can also create internal setters for derived state which are simply functions that return a value and is used directly in the template.

const MyComponent = () => { const [count, setCount] = state(0); // the limitMessage is read on every template update // and because it is a setter function (dynamic expression) it // will be called along with everything const limitMessage = () => count() > 10 ? "Counted passed limit" : "" const countUp = () => { setCount(count() + 1) } template`

${count}

${limitMessage}

`; }

Every update causes every dynamic expression in the template to be called to check if value changed so the DOM can be updated accordingly. You can use this feature to create derived states which should be evaluated along with other state change saving you from creating many state data.

This can also be used for props changes. Bellow is an alternative example using props.

const MyComponent = (props) => { const dispatch = eventDispatch(); const limitMessage = () => props.count() > 10 ? "Counted passed limit" : "" const countUp = () => { dispatch() } template`

${props.count}

${limitMessage}

`; }
