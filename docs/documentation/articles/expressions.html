Expressions

Cube templates are template literals therefore can include expressions which can be dynamic or static.

Static Expressions

Static expressions are anything you don't want the template to react to if they change. This means that after everything is rendered, no matter the change the DOM elements will remain the same.

let label = "click me"; let type = "button"; const Button = html``; Button.render(document.body); // renders: // update data label = "clicked"; type = "reset"; // trigger update to check for changes and // update rendered DOM elements accordingly Button.update(); // nothing changes and things remain rendered as //

The html template literal tag will return an HTMLTemplate instance which has the render method to put elements on the DOM and update to update the elements according to data changes.

This API is what powers Cube. Behind the scenes Cube is calling these methods whenever changes are detected and the template is doing all the work making sure the DOM only gets updated on changes and elements are rendered according to the data snapshot.

Dynamic Expressions

A dynamic expression is simply and expression returned by a function.
