Conditional Attributes

Every HTML templating system has or must have a way to dynamically set attributes and Cube is no different.

Built-in is the ability to prefix attributes with attr and add a condition for which they should be set.

const disabled = false; // only adds the disabled attr is "disabled" is true html``

Boolean Attributes

Pattern: attr.NAME="CONDITION"

Boolean attribute is a special HTML attribute that does not require the attribute to have a value with few exceptions. Cube knows about these attributes and do not require a value to be specified.

const disabled = false; const checked = true; // only set "disabled" attribute if disabled is TRUE html`` // only set "checked" attribute if showPlaceholder is true html``

These boolean attributes will only require the condition to be specified therefore being the easiest attribute to set.

Style Attributes

Pattern: attr.style="CSS | CONDITION" or attr.style.CSS_PROPERTY_NAME="CSS_PROPERTY_VALUE | CONDITION"

Conditional styling is powerful in a sense that you can target specific CSS property and dynamically set style which allows developers to do amazing things.

const disabled = true; const ctaButton = true; // set a single style property conditionally html`` // set css style conditionally html``

Class Attributes

Pattern: attr.class="CLASS_NAMES | CONDITION" or attr.class.CLASS_NAME="CONDITION"
