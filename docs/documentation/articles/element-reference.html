Element Reference

Although rarely, there will be times when you will need reference of the DOM elements created from the template you define. For that, Cube templates has a special attribute called ref.

This attribute marks the element you want to gain reference of, and it takes a name from which you want to access it.

The references will also work in case of dynamic elements. For example, in cases where elements are conditionally rendered.
