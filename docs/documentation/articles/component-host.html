Component Host

A component host is the component element that wraps all the content. When you create a Cube component you define a tag and with it, you can render things in the DOM. That is the host.

Inside the function you use to create a component, you don't have access to the host. The function simply is used to define the body of the component and the logic related to it.

const MyComponent = () => { template`

Hello World

` } register(MyComponent)

Cube exposes a helper that gives you access to it called host that you can use to gain access and do anything you need to do.

const MyComponent = () => { const comp = host(); template`

Hello World

`; comp.setAttribute("id", "example") } register(MyComponent)

Accessing the host should be a rare occurrence, and you should never need to set attributes directly on the host, especially an observed one. You can use it to access things around the host element.

Host styling

You also have access to the host via CSS as well. the selector is :host and you can use it to apply any style to it or react to certain attributes set on it.

:host { display: block } :host([id="example"]) { background: blue; }

Learn more about CSS host selector and check out the documentation on Cube component styling for additional tips and tricks.
