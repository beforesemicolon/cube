Routing

Cube comes with a simple routing system built-in. It allows you to navigate around as well as reacting to routing changes.

goToPage

The goToPage let you specify the page you want to go to.

goToPage("/some-page")

You can also specify the state and title as the second argument optional options.

goToPage("/some-page", {someData: "for the page"}, "Some Page Title")
