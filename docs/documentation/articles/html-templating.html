Templating

Cube has a very powerful templating system based on function which allows for many things to be added to it to handle very specific HTML syntax and logic.

Cube allows you to define the template using two template literals tags:

  • html => Used to define elements;
  • template => Used to define component template bodies;
import {html, template} from "@beforesemicolon/markup";

As a matter of fact, the templating system is an independent piece which Cube is built upon. You can explore the templating system or even use it alone by installing the @bfs/html package.

npm install @beforesemicolon/markup

Element

An element is anything you define using the html helper. It can be done independently of a component existing. For example, this is a simple button element:

const Button = html``;

To render an element, you can simply call the render method on it passing an DOM element where the element will be appended to.

Button.render(document.body)

To make an element reusable, you can consider creating functions that return them. This is powerful because you can use the arguments of the function to set template expressions to make each template unique based on provided data.

const TodoItem = (name) => html`
  • ${name}

      ${TodoItems}
    `; TodoList.render(document.body)

    Template

    A template can only be defined inside a component function, and it is done by using the template helper which is a special html helper which is tied to the component. This means that everything you can do with html template string tag you can with template.

    Injecting HTML

    Cube templates will handle html and HTMLElement instances. It also handles arrays containing these.

    const span = document.createElement("span"); span.textContent = "sample"; html``; // renders:

    Everything else is treated as text. Bellow example will not render the span as HTML. It will be just an HTML string on the DOM which makes things pretty easy and that's one thing that makes Cube special and safe.

    Unlike other UI frameworks, everything is rendered as text, and you need to tell it when to render things using html template string tag or passing real HTMLElement instances.

    const htmlString = ""; html`
    ${htmlString}
    `;

    However, if you have a string you want to render, which is normal usecase, you can still use html but as a function.

    const span = "sample"; html``;

    The html template string tag can be called with an array of HTML strings which it can then render.

    You should only use this method with trusted HTML string or properly testing for HTML injections.
