Repeat/List Content

A powerful templating system will allow you to avoid repeating yourself. A lot of what we render is based on data and when there is a lot of data you will need a templating system that will simplify it.

Cube will handle arrays by default. This makes it easy to render long lists.

const TodoItem = (name) => html`
  • ${name}
    • `; const TodoItems = ["item 1", "item 2", "item 3"]; const TodoList = html`
      ${TodoItems.map(TodoItem)}
    `; TodoList.render(document.body)

    The above example is perfect to render static lists but if you have a dynamic list, one you update frequently, you need to make the render dynamic.

    const TodoList = html`
      ${() => TodoItems.map(TodoItem)}
    `;

    By turning it into dynamic expression the elements will update according changes. However, this means that every time there is a change causing an entire DOM change.

    Instead, it is better to keep a list of html instances of Node.

    const TodoItem = (name) => html`
  • ${name}
    • `; const TodoItems = ["item 1", "item 2", "item 3"].map(TodoItem); const TodoList = html`
      ${() => TodoItems}
    `; TodoList.render(document.body)

    Then you can modify the list as you wish and the DOM will only udpate where things have changed

    // add new item to the list TodoItems.push(TodoItem(`item 4`)) // apply the changes to the DOM TodoList.update()

    But all this is painful to track therefore Cube has the repeat helper that handles all this for you.

    repeat Helper

    The repeat helper is a special templating tool that handles lists and any type of repetitions on the DOM. It does all the caching and tracking while being data based.

    It takes a number, an array, or a function that will return a number or array.

    // provide a number and a callback that renders each number html`${repeat(5, n => n)}` // provide an array and a callback that renders each item html`${repeat([1, 2, 3], n => n)}` // dynamically get a list count or array and a callback that renders each item html`${repeat(() => Math.floor(Math.random() * 10), n => n)}`

    Everything you return by the callback will be associated with each item from the list. This means if the list have repeated items, they will render once as a DOM element. This is true for primitive values only.

    html`${repeat([1, 3, 5, 3], n => `item-${n}`)}` // renders: item-1item-3item-5item-3 html`${repeat([1, 3, 5, 3], n => html`item-${n}`)}` // renders: item-1item-3item-5

    As you can see from above example, whenever you are mapping a data to a DOM element will result in unique DOM elements regardless of repeated primitives in the list. This is because each data will be mapped to a html instance therefore 3 will be mapped to the same DOM element and the same DOM element cannot exist twice in the Document.
