HTMLComponentElement Creation

Cube is web UI framework. Although it creates web components first, it can be used to create any type of components. It really depends on which way you prefer.

Cube HTMLComponentElement

Cube components are simply functions you can register as a web components.

const MyComponent = () => {} // valid component register(MyComponent)

Components don't have to render anything which means you can use them as data providers, to run some logic, etc. However, if you are rendering something you need to use the Cube template template literal tag.

const MyComponent = () => { template`

Hello World

` } register(MyComponent)

The template is a special html template literal tag which is tied to the component and also the only one that allows you to use native web component APIs like slot.

By default, Cube creates a web component with a shadow root in an open mode. You can change this by playing with the configuration of the component to even remove the shadow root. Learn more.

HTMLComponentElement name

The name of the function you use to create components is very important. Cube will use the function name to define the tag name of the component element.

This means that MyComponent becomes my-component tag name.

A valid component function name must be at least two words camelcase. This is according the custom elements valid name specifications. An error will be thrown if this is not the case.

Function HTMLComponentElement

What if you don't want web components? Well, Cube templating system is the most powerful part of the framework ,and you can use it by itself.

Since components are just functions, you can create one that returns a html instance and then render it.

const MyComponent = () => { return html`

Hello World

` } MyComponent.render(document.body); // append it to the document
