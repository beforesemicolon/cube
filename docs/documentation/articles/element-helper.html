element helper

The element helper is the simplest helper because all it does is allow you to create elements in one call.

So instead of this:

const btn = document.createElement("button"); btn.className = "btn cta"; btn.setAttribute("disabled", ""); btn.innerHTML = "click me"

You can do this:

const btn = element("button", { attributes: { disabled: true, class: "btn cta" }, htmlContent: "click me" });

Why it exists

It actually does not just help you create elements in one call. It does many things that can help you with component elements like properly setting prop values for the component on creation.

For example, when you create Cube components, the props become properties in the component instance. This properties can be simple primitive values but could also be complex data type like a Map or Array. The element helper will ensure that they are properly set in the component where via the attribute would be harder to do.

const MyButton = () => {...} const {tagName} = register(MyButton, {disabled: true}); const btn = element(tagName); // MyButton instance
