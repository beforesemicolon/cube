Conditional Render

Cube templating system tracks the DOM for you and knows what changes based on data. It also remembers the rendered DOM which make conditional rendering elements optimal.

Conditional rendering is as easy as setting ternaries in the template.

const status = "done"; html`
${() => status == 'pending' ? html`Pending` : html`Done` }
`;

The above example is using a dynamic expression to set the status and this is not optimal because every time the function is called by the Cube template, it will create new instances of the html. In this case it's pretty small, but it could be a large markup.

Instead, you can create instances and use them in the dynamic expression.

const status = "done"; const pendingSpan = html`Pending`; const doneSpan = html`done`; html`
${() => status == 'pending' ? pendingSpan: doneSpan}
`;

when helper

Cube template has few helpers and one of them is the when helper you can use specifically for conditional rendering.

Bellow is the same example as above ones but using the when helper which already handles all the performance issues already mentioned. This is because when caches the result and does everything for you.

const status = "done"; html`
${when(() => status == 'pending', html`Pending`, html`Done`)}
`;

The when helper takes a condition, a truthy value, and an optional falsy value, and all of these can be functions.

Condition as function same as a dynamic expression and the other arguments as function is ideal to lazy load content.

let loading = true; const sample = html`${when( () => loading, html`

loading...

`, // lazy load the rest () => html`

loaded

` )}`; setTimeout(() => { loading = false; sample.update(); }, 2500)

Using the function to render content will delay it for when the condition is met.
