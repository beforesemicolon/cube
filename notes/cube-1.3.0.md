# Cube 1.3.0

- Use the new double variant of `cb-range-slider` to select lower and upper
  values on one track with the pointer or keyboard.
- Existing sliders still default to the single variant and retain their scalar
  value, events, and form behavior.
- The Playground and documentation show both variants.

The version-pinned package, browser bundles, and AI references become public
after npm publication.
