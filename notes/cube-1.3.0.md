# Cube 1.3.0

- Use `cb-range-input` for one value by default, or set `variant="double"` to select a lower and upper value on one track.
- Existing `cb-slider` and `cb-range-slider` tags and imports keep their published behavior. Use Range Input for new code.
- Use `cb-progress-steps` for dots (default) or lines. Each reachable step emits one click event with its zero-based index.
- Each component has one Playground story. Change the variant in Controls to try the other mode.

The version-pinned package, browser bundles, and AI references become public
after npm publication.
