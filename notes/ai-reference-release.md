# Cube 1.2.0 candidate

This candidate stacks on the separate, open 1.1.0 release change. Review and
release 1.1.0 first. This change advances the package, root lockfile entry,
and component registration brand to 1.2.0. It does not require a new
runtime dependency or raise the WebComponent npm dependency minimum.

The release build creates a versioned AI index and individual records for
all public elements, plus the Custom Elements Manifest and theme tokens.
The docs build copies those same generated bytes into `ai/1.2.0/`. The
registry CDN is the durable versioned reference for this release; a docs
redeploy need not preserve the copies of earlier releases.

After the owner publishes the dependency and Cube, verify:

1. Fetch `https://cdn.jsdelivr.net/npm/@beforesemicolon/cube@1.2.0/ai/index.json`;
   confirm status 200, package name, and version.
2. Follow `records/cb-button.json` and `records/cb-audio-player.json` relative
   to the index. Confirm the same version and that all referenced browser
   scripts and fixtures return 200.
3. Fetch `https://cdn.jsdelivr.net/npm/@beforesemicolon/cube@1.2.0/custom-elements.json`;
   confirm its schema version and the element definitions.
4. Install the published packages into a new application. Test a named
   icon-only action by keyboard using only the public entry points.
